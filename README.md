# Web Dev Pro — una sola página

Sitio estático con HTML, CSS y JavaScript separados. WhatsApp: 0998722824 (+593998722824).

## Abrir en tu computadora
Abre index.html. Mantén styles.css, script.js y logo.png junto al HTML.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado web-dev-pro en GitHub.
2. Extrae este ZIP. Sube sus archivos directamente a la raíz del repositorio con Add file > Upload files; no subas el ZIP ni una carpeta que contenga todo.
3. Guarda los archivos con Commit changes.
4. Ve a Settings > Pages.
5. En Source selecciona Deploy from a branch.
6. Elige main y /(root), después Save.
7. Espera a que termine la publicación. GitHub mostrará el enlace en esa sección.

Documentación: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Editar
- index.html: textos, servicios y planes.
- styles.css: colores, tamaños y diseño adaptable.
- script.js: número de WhatsApp y mensaje del formulario.
- logo.png: logo de la marca, mostrado pequeño para conservar su nitidez.

Los botones de contacto abren WhatsApp. El cliente revisa el mensaje y pulsa Enviar; la web no envía mensajes por sí sola.
